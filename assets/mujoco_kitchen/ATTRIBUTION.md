# 场景数据来源

本目录的数据由下面两个数据集转换而来：格式换成了 MuJoCo 用的网格和 JSON，非凸碰撞体换成了凸包和方盒，贴图缩小到 512 像素以内。

| 数据 | 作者 | 许可证 |
|---|---|---|
| [ReplicaCAD](https://aihabitat.org/datasets/replica_cad/)：家具和家居用品 | Facebook, Inc. 及其关联方 | [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)，**仅限非商业用途** |
| [YCB Object and Model Set](https://registry.opendata.aws/ycb-benchmarks/)：食品、餐具、水果等物品 | Yale University、Berkeley 等 | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

YCB Object and Model Set 引用自 https://registry.opendata.aws/ycb-benchmarks ，访问日期 2026-11-05。

本目录是非商业数据，使用和再分发都要遵守上述许可证。
